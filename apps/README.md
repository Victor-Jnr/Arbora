# Apps

Desktop surfaces for Arbora.

## Desktop chat (Tkinter)

Plan → approve → execute in a native window, sharing the same broker runtime as the CLI.

```powershell
pip install -e ".[dev]"
arbora-ui
```

Or:

```powershell
python -m apps.desktop_chat
```

Uses forest/ink chrome, provider selector (echo/ollama), dry-run toggle, trusted-routine awareness, and hard-confirmation dialogs for sensitive steps.
